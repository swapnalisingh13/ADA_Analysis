# ADA_Analysis

Air Quality Prediction- AirCall

This Jupyter Notebook implements deep learning models to predict Air Quality Index (AQI) from images of air pollution.

Dataset

Contains 12,240 images from 7 cities in India and 1 in Nepal.

Images are classified into 6 AQI levels: Good, Moderate, Unhealthy for Sensitive Groups, Unhealthy, Very Unhealthy, Hazardous/Severe.

CSV file includes: Location, Filename, Year, Month, Day, Hour, AQI, PM2.5, PM10, O3, CO, SO2, NO2, AQI_Class.

Dataset is publicly available: Air Pollution Image Dataset from India and Nepal

### Models

The notebook trains and evaluates five deep learning models:

EfficientNetB7

ResNet50

VGG19

Inception

Xception

### Evaluation Metrics

Accuracy

Precision, Recall, F1-Score

MSE, MAE, RMSE
